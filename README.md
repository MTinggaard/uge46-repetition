# Uge 46 – Repetition

Dette IntelliJ-klare Maven-projekt indeholder tomme Java-klasser til mandag, tirsdag og onsdag i uge 46.

## Åbn projektet

1. Pak ZIP-filen ud.
2. Åbn IntelliJ IDEA og vælg **File → Open**.
3. Vælg mappen `uge46-repetition` (med `pom.xml`).
4. Vælg et JDK på mindst version 17, hvis IntelliJ spørger.
5. Åbn `src/main/java/dag1_grundlaeggende` og kør den ønskede klasses `main`.

**Mandag:** `dag1_grundlaeggende`, med `OpgaveA1` til `OpgaveA8` og `Opgave1` til `Opgave13`.

**Tirsdag:** `dag2_objektorienteret`, med én under-package pr. opgave og tomme klasser, interfaces og enums. Forudsig-opgaverne ligger i `forudsig`.

**Onsdag:** `dag3_robust_persistent`, med én under-package pr. opgave. Tomme testklasser ligger i `src/test/java`, og JUnit 5 er konfigureret i Maven.

Tirsdagens og onsdagens klasser er kun skeletter: du skriver selv felter, konstruktører, metoder, arv, interfaces og tests. Onsdagens opgave om medier genbruger tirsdagens `dag2_objektorienteret.medier`.

Der er ikke tilsvarende repetitionsopgaver til torsdag og fredag i dette forløb.

Skriv selve opgavelogikken i `static`-metoder, der returnerer resultater. Brug `main` til at udskrive og afprøve dem. Opgave 13 er en undtagelse med udskrivende metoder.
